## 桌面弹弹弹 · 朋友的酒 v1.0.0

一款 Windows 桌面视觉特效与音画同步演示程序（C# + GDI/DWM）：以 130 BPM 的音乐为时间基准，
把桌面图标与窗口的弹性动画、整屏图像序列、屏幕滤镜统一到同一条时间线上，最后播放一段收尾动画。
纯本机运行，不联网、不修改系统文件、不读写用户数据。

### 功能

- **节奏驱动**：130 BPM、406 拍、拍长 0.4615 s，音频 187.371 s。不靠计时器推拍，每帧读取音频已播采样数计算相位，机器卡顿后下一刻立即回到正确位置。
- **图标弹性动画**：接管桌面图标层，原图标隐藏，屏上只剩按节奏弹动的图标；整数像素落位，标签按资源管理器规则断行。
- **窗口弹性动画**：同一套公式作用于所有可见窗口，运行中新开的窗口半秒内加入；最大化窗口被压回屏幕 70% 高度。
- **整屏图像序列**：视频按 25 fps / 640×360 拆成 4683 张 jpg，按音乐位置取帧，由独立 25 fps 线程经穿透分层窗口绘制（壁纸之上、图标与窗口之下），卡顿只掉帧不停播。
- **屏幕滤镜**：每拍抖动 ±4 px、反色、残影、切条；第 1.2 秒起常驻撕裂；七种 NetGDI 滤镜（反色、模糊、圆形隧道、阴影画刷、图案画刷、颜色滤镜、屏幕融化）由独立宿主进程 `NgdiRun.exe` 承载。
- **桌面弹窗**：原生对话框随机弹出（上限 5 个）；两个置顶视频小窗每两拍平滑换落点、始终夹在屏幕内；另有一个跟随鼠标的置顶窗口。
- **自动打开系统工具**：从 19 项白名单里随机拉起，**上限 4 个**，开第 5 个时先关最早那个。
- **结束流程**：音乐播完 → 关闭全部弹窗与外部进程 → 播放收尾音 → 收尾卡片 + 满屏飘字 → 定格 30 秒（随时可退出）。

### 兼容性与安装

- 支持 **Windows 7 SP1 / 8.1 / 10 / 11（64 位）**；`%TEMP%` 所在盘需留约 390 MB。
- 首次运行由 Python 外壳预检 .NET 4.8：缺失则静默安装，返回 `3010/1641` 时登记一条 RunOnce，重启后自动续跑，无需用户再次操作。
- Win7 额外先装官方 SHA-2 补丁 `KB4474419`；**Win7 SP0（版本 7600）会被直接拦截**并提示升级到 SP1，不进入安装流程。
- 安装失败不关窗：可「重试静默安装」「手动安装（显示进度）」「打开安装日志」（`%LOCALAPPDATA%\朋友的酒\dotnet_install.log`）。
- 退出：`Ctrl + Alt + Q` 或 `Ctrl + Shift + Q`；任务管理器强制结束也不会把桌面留在异常状态。

### 已知限制

- 整屏图像序列为 640×360 放大到全屏，清晰度偏软；提高分辨率会让分发包体积成倍增长。
- 被自解压结构与画面改动影响，部分杀毒软件会误报，加白名单即可，程序不联网。
- 分层窗口位于壁纸之上、图标与窗口之下，因此整屏滤镜会短暂盖住图像序列，下一帧补回。
